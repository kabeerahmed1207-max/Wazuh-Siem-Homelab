# Dashboards and Reports

## Overview

Wazuh provides both pre-built and custom visualization capabilities.

## Lab Activities

- Explored the **Demo Dashboard**
- Viewed total events and agent distribution
- Created a simple custom visualization (Pie chart by `agent.name`)
- Navigated through available dashboards for security events, vulnerabilities, and compliance

## Key Capabilities

- Pre-built dashboards for common use cases
- Ability to create custom visualizations
- Combine multiple panels into a single dashboard
- Strong reporting features for management and compliance

## Takeaway

Dashboards turn raw alerts into actionable insights. Custom visualizations help SOC analysts and managers quickly understand the security posture of the environment.
