# IT Hygiene

## What is IT Hygiene in Wazuh?

IT Hygiene provides detailed inventory and system information collected from agents. It is very useful for both security and IT/GRC teams.

## Main Sections Explored

### 1. System
- Hardware details
- Hostname
- Network interfaces
- Operating system version

### 2. Software
- Installed programs and packages
- OS patches
- Browser extensions

### 3. Network
- Listening ports (useful for exposure management)
- Example: RDP, SSH, web services

### 4. Identity
- Local user accounts
- User privileges

## Lab Activity

- Opened the Windows agent → **IT Hygiene** tab
- Reviewed installed software and listening ports
- Checked the Linux agent for system and package information

## Why It Matters

IT Hygiene gives excellent visibility into what is actually running on endpoints. This helps with:

- Asset inventory
- Identifying unauthorized software
- Exposure management (open ports)
- Compliance and auditing
