# Configuration Assessment (CIS Benchmarks)

## Overview

Wazuh can audit endpoints against security baselines, especially **CIS Benchmarks**.

This feature checks for common misconfigurations and security hardening issues.

## In the Lab

- Navigated to the Linux agent → **Configuration Assessment** tab
- Reviewed the CIS Benchmark score
- Examined individual checks that passed or failed

## Key Points

- Provides a compliance score (e.g., 65%)
- Highlights specific hardening recommendations
- Useful for GRC, system administrators, and security teams
- Can be customized with additional policies

## Takeaway

Configuration Assessment helps identify weak security settings before attackers can exploit them. It is one of the most practical features for improving baseline security.
